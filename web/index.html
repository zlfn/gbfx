gb-image-fx 0.1.0

by zlfn

Images become the tile data, palettes, attributes and tile map a Game Boy or Game Boy Color program loads. This converter is the gb-image-fx crate compiled to WebAssembly.

The ROM is written in pure Rust!

Game Boy cartridges are usually built in C or assembly. The one you can download here is not: it is built with rust-gb.

Read its source

What it uses

Palette reduction
A port of tiledpalettequant by rilden. Eight four-colour palettes and the squares that use them are settled together, growing a colour at a time and handing the budget to whichever palette carries the most error.
Screen correction
The CGB display model (Modern Balanced) from SameBoy by Lior Halphon, run backwards so the colours land where they started.
Decolorize
The contrast preserving decolorization of Lu, Xu and Jia, through the decolorize crate, so colours that differ in hue but not in lightness stay apart.
Dithering
Blue noise, Bayer, or a plain ordered pattern, weighted against the error each choice leaves behind.
